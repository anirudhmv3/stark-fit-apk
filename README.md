# Stark Fit - GitHub Auto Build (NO Android Studio)

This zip builds APK automatically on GitHub for FREE.

Steps:
1. Go to github.com/new -> Create repo stark-fit-apk (Public)
2. Click "uploading an existing file" -> Drag ALL files from this zip including .github folder (show hidden files)
3. Commit
4. Go to Actions tab -> Wait 3-5 mins for Build Stark Fit APK to finish (green tick)
5. Click the run -> Scroll to Artifacts -> Download StarkFit-APK -> Unzip -> app-debug.apk -> Install on phone

Features in this build:
- Welcome Name+Gender, Sir/Ma'am detection
- Voice ends with Sir/Ma'am
- 4 meals Breakfast Brunch Lunch Dinner
- Custom foods permanently saved
- Fiber logic (Total, Fiber, Net Carbs, Protein, Fat)
- Live Pie Chart
- Black Blue Iron Man theme
- Data survives shutdown (localStorage + IndexedDB)
- Export to mail

If build fails, click Re-run failed jobs.

Alternative: Open live app link in Chrome -> Add to Home Screen -> Works like APK.
